17: Conditional Probability Revisted

Recall that for two events A and B, with P(A)>0, the conditional probability of A given B is

P(A\mid B)=\frac{P(A\cap B)}{P(B)}

Learning that B has occurred can change the set of possible outcomes under consideration.

We now extend this idea from events to random variables.

The Discrete Case

Suppose X and Y are discrete random variables with joint probability mass function p_{X,Y}(x,y)=P(X=x,Y=y)

What we want is the probability that X=x, given that we know Y=y.

By applying the definition of conditional probability we have:

P(X=x\mid Y=y) = \frac{P(X=x,Y=y)}{P(Y=y)}.

Therefore, the conditional probability mass function of X given Y=y is:

p_{X\mid Y}(x\mid y)=\frac{p_{X,Y}(x,y)}{p_Y(y)}

where

p_Y(y)>0

and

p_Y(y)=\sum_x p_{X,Y}(x,y)


Note that if Y=y is fixed, then we have just an ordinary PMF for X.

Conditional Cumulative Distribution Function

Just as an ordinary PMF determines a CDF, the conditional PMF determines the conditional CDF:

F_{X\mid Y}(x\mid y) = P(X\leq x\mid Y=y) = \sum_{t\leq x}p_{X\mid Y}(t\mid y)

The conditional CDF describes the distribution of X after we have specified the value of Y.

Conditional Expectation

Recall that the expectation of a discrete random variable is:

E[X]=\sum_x x\,p_X(x)

If we know that Y=y, we use the conditional distribution:

E[X\mid Y=y]=\sum_x x\,p_{X\mid Y}(x\mid y)

Equivalently using the definition of conditional probability, we can write this as:

E[X\mid Y=y] = \frac{\sum_x x\,p_{X,Y}(x,y)}{p_Y(y)}

Note that now since we can condition on another random variable, we do not necessairly have a number as the result of the expectation. Instead, we can have a random variable as the result of the expectation.

  • E[X] is a number representing the unconditional mean of X.

  • E[X\mid Y=y] is a number representing the mean of X when Y is fixed at a particular value y.

  • E[X\mid Y] is itself a random variable, obtained by evaluating the conditional mean at the observed value of Y.

For example, if g(y)=E[X\mid Y=y], then E[X\mid Y]=g(Y).

Consider the joint PMF

\begin{aligned} P(X=1,Y=1)&=0.5\\ P(X=1,Y=2)&=0.1\\ P(X=2,Y=1)&=0.1\\ P(X=2,Y=2)&=0.3 \end{aligned}

We want to calculate E[X\mid Y=1].


It is often easier to view the joint PMF as a table:

Y=1 Y=2 p_X(x)
X=1 0.5 0.1 0.6
X=2 0.1 0.3 0.4
p_Y(y) 0.6 0.4 1.0


We now need to determine the conditional distribution. We know that Y is restricted to 1, so we need only to concern ourselves with the first column of our table.

P(Y=1)=0.5+0.1=0.6.

We then have,

P(X=1\mid Y=1)=\frac{0.5}{0.6}=\frac56

and

P(X=2\mid Y=1)=\frac{0.1}{0.6}=\frac16.

Now we can calculate the conditional expectation:

\begin{aligned} E[X\mid Y=1] &=1\cdot P(X=1\mid Y=1)\quad+2\cdot P(X=2\mid Y=1)\\ &=1\cdot\frac56+2\cdot\frac16. \end{aligned}

Thus,

E[X\mid Y=1]=\frac{7}{6}

Assuming the same joint PMF from the above example, what if we instead condition on Y=2?

Similarly as to before, we obtain:

P(X=1\mid Y=2)=\frac{0.1}{0.4}=\frac14

and

P(X=2\mid Y=2)=\frac{0.3}{0.4}=\frac34.

Therefore,

E[X\mid Y=2] =1\cdot\frac14+2\cdot\frac34 =\frac74.

After this, we now have the complete conditional expectation function

g(y)= \begin{cases} \frac{7}{6},&y=1,\\ \frac{7}{4},&y=2. \end{cases}

And so, E[X\mid Y] is a random variable that takes these two values according to the value of Y.

Note that averaging the conditional expectations according to the probabilities of Y gives

\begin{aligned} E[g(Y)] &=\frac76(0.6)+\frac74(0.4)\\ &=1.4\\ &=E[X]. \end{aligned}

First, you should verifiy that E[X] = 1.4.

Seeing this, we have that averaging the conditional expectations over all the probabilities of Y gives us the expectation of X itself. This is an instance of the law of total expectation, which we will cover as a general principle further on.

Obtaining Distributions by Conditioning

Conditioning can transform one probability distribution into another.

Suppose X_1\sim\operatorname{Binomial}(n_1,p) and X_2\sim\operatorname{Binomial}(n_2,p) with X_1 and X_2 independent.

We want to determine P(X_1=k\mid X_1+X_2=m).

 

We first apply our definition of conditional probability:

P(X_1=k\mid X_1+X_2=m) = \frac{P(X_1=k,X_1+X_2=m)} {P(X_1+X_2=m)}.

We can then do some rearrangment from X_1=k,\quad X_1+X_2=m to X_1=k,\quad X_2=m-k. We then have:

P(X_1=k\mid X_1+X_2=m) = \frac{P(X_1=k,X_2=m-k)} {P(X_1+X_2=m)}.


We will now rewrite the numerator. Because we know that X_1 and X_2 are independent we have that:

P(X_1=k,X_2=m-k) =P(X_1=k)P(X_2=m-k).

Then using their binomial PMFs,

P(X_1=k) =\binom{n_1}{k}p^k(1-p)^{n_1-k}

and

P(X_2=m-k) =\binom{n_2}{m-k}p^{m-k}(1-p)^{n_2-m+k}.

Our resulting numerator is then:

P(X_1=k,X_2=m-k) = \binom{n_1}{k}\binom{n_2}{m-k} p^m(1-p)^{n_1+n_2-m}.


Now we rewrite the denominator. We will use a useful property of independent binomial random variables where if they have the same success probability then their sum is also a binomial random variable that has the form:

X_1+X_2\sim\operatorname{Binomial}(n_1+n_2,p).

Our demoninator is then:

P(X_1+X_2=m) = \binom{n_1+n_2}{m} p^m(1-p)^{n_1+n_2-m}.


After our rewrites, we now have:

\frac{ \binom{n_1}{k}\binom{n_2}{m-k} p^m(1-p)^{n_1+n_2-m} }{ \binom{n_1+n_2}{m} p^m(1-p)^{n_1+n_2-m} }.

Note that the probability terms cancel, giving us

P(X_1=k\mid X_1+X_2=m) = \frac{\binom{n_1}{k}\binom{n_2}{m-k}} {\binom{n_1+n_2}{m}}

for

\max(0,m-n_2)\leq k\leq\min(n_1,m).

This is the hypergeometric distribution.

The process of conditioning in this example converted our problem into a fundamentally different one than what is represented by the binomial distribution.

Before conditioning, the number of successes in each group is binomial. But after conditioning on the total number of successes, the problem becomes one of allocating a fixed number of successes across two groups. This is the same as the sampling-without-replacement problem represented by the hypergeometric distribution.

Where if have n_1 red balls and n_2 green balls. If we select m balls uniformly without replacement, the probability of selecting exactly k red balls is

P(X=k) = \frac{\binom{n_1}{k}\binom{n_2}{m-k}} {\binom{n_1+n_2}{m}}.

Something important in the above expression is that the resulting conditional distribution does not depend on p. This happens because knowing the total number of successes eliminates the information contributed by the common success probability, leaving only the combinatorial allocation of those successes.

Suppose that X_1\sim\operatorname{Poisson}(\lambda_1) and X_2\sim\operatorname{Poisson}(\lambda_2) where the random variables are independent and \lambda_1,\lambda_2>0.

We will determine the conditional PMF of X_1 given X_1+X_2=n.

First, we will write the conditional probability. For k=0,1,\ldots,n

P(X_1=k\mid X_1+X_2=n) = \frac{P(X_1=k,X_2=n-k)} {P(X_1+X_2=n)}.


Next, we will evaluate the numerator.

Using independence and the Poisson PMF,

\begin{aligned} P(X_1=k,X_2=n-k) &= \frac{e^{-\lambda_1}\lambda_1^k}{k!} \frac{e^{-\lambda_2}\lambda_2^{n-k}}{(n-k)!}\\ &= \frac{e^{-(\lambda_1+\lambda_2)} \lambda_1^k\lambda_2^{n-k}} {k!(n-k)!}. \end{aligned}


Finally, we will evaluate the denominator.

Using the property that the sum of independent Poisson random variables is Poisson, with parameter equal to the sum of the individual parameters, we have:

X_1+X_2\sim\operatorname{Poisson}(\lambda_1+\lambda_2)

and

P(X_1+X_2=n) = \frac{e^{-(\lambda_1+\lambda_2)} (\lambda_1+\lambda_2)^n}{n!}.

Substituting and canceling gives us:

\begin{aligned} &P(X_1=k\mid X_1+X_2=n)\\[2mm] &\quad= \frac{n!}{k!(n-k)!} \frac{\lambda_1^k\lambda_2^{n-k}} {(\lambda_1+\lambda_2)^n}. \end{aligned}

Recognizing the binomial coefficient lets us rewrite the above as:

P(X_1=k\mid X_1+X_2=n) = \binom nk \left(\frac{\lambda_1}{\lambda_1+\lambda_2}\right)^k \left(\frac{\lambda_2}{\lambda_1+\lambda_2}\right)^{n-k}

This is a binomial PMF with success probability

q=\frac{\lambda_1}{\lambda_1+\lambda_2}.

Therefore,

X_1\mid(X_1+X_2=n) \sim \operatorname{Binomial} \left(n,\frac{\lambda_1}{\lambda_1+\lambda_2}\right)

Considering our above example, imagine two independent sources generating events.

Source 1 produces events at an average rate \lambda_1 while source 2 produces events at an average rate \lambda_2.

Without additional information, the event counts from the two sources are independent Poisson random variables.

If we observe exactly n events in total, then conditioned on this information, each observed event can be attributed to source 1 with probability

\frac{\lambda_1}{\lambda_1+\lambda_2}.

Thus the number attributable to source 1 is binomially distributed.

This is useful in applications involving arrivals, queueing systems, reliability, and event-count models.

Consider an experiment with three possible outcomes where each trial produces outcome 1, 2, or 3, with respective probabilities p_1,\qquad p_2,\qquad p_3, where p_1+p_2+p_3=1.

Suppose n independent trials are performed and let X_i denote the number of trials producing outcome i.

We will to determine E[X_1\mid X_2=m].


First, we note that the random vector (X_1,X_2,X_3) follows a multinomial distribution:

(X_1,X_2,X_3) \sim\operatorname{Multinomial}(n;p_1,p_2,p_3).

Where X_1+X_2+X_3=n.


Now, knowing that X_2=m tells us that exactly m of the trials produced outcome 2. Then, the remaining n-m trials must have produced outcome 1 or outcome 3. Understanding this, we know that we now need to renormalize the probabilities of these remaining outcomes.

In a trial that does not produce outcome 2, the probability of outcome 1 is

P(\text{outcome 1}\mid\text{not outcome 2}) = \frac{p_1}{1-p_2}.

Since 1-p_2=p_1+p_3 we have

P(\text{outcome 1}\mid\text{not outcome 2}) = \frac{p_1}{p_1+p_3}.


Among the n-m remaining trials, each produces outcome 1 with the conditional probability we just found above.

Therefore,

X_1\mid X_2=m \sim \operatorname{Binomial} \left(n-m,\frac{p_1}{1-p_2}\right).

This holds for p_2<1 whenever the conditioning event has positive probability.

We can now finally compute the expectation. The expected value of a binomial random variable with parameters r and q is rq and so the expectation is:

E[X_1\mid X_2=m] = (n-m)\frac{p_1}{1-p_2} = (n-m)\frac{p_1}{p_1+p_3}

Note that the expected count is not simply (n-m)p_1.

This is because the original probability p_1 describes the chance of outcome 1 before any restrictions are imposed. Once we know that a trial was not outcome 2, the relevant probability becomes

\frac{p_1}{1-p_2}.

Conditioning changes the entire distribution, not only the number of trials.
